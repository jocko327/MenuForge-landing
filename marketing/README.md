# Campaign docs

Markdown campaign specs, checklists, and scorecards for MenuForge ads and
marketing. These files are **not** served by nginx — only the HTML/CSS/JS at
the repo root and under `assets/` are public.

Ship changes on **`main`** in this repo (`MenuForge-landing`). They are
**not** part of the app `staging` → `main` promotion cycle.
